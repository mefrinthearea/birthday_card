# Birthday Invitation Card

A static invitation design implemented as a browser-rendered layout.

## Features

Typographic hierarchy, image placement, event details and a structured card layout.

## Technology

HTML, CSS and Google Fonts.

## Getting started

```sh
git clone https://github.com/mefrinthearea/birthday_card.git
cd birthday_card
```

Open `birthday_card/index.html` in a browser. No package installation or build step is required. External fonts or icons may require an internet connection.

## Entry point

`birthday_card/index.html`

## Scope and limitations

The invitation content is illustrative. No event registration or dynamic functionality is implemented.

## Project status

Early learning project retained to document development progress. Source reviewed for documentation; runtime behavior has not been re-tested in this update.
